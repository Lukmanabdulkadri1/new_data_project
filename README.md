# 🚀 New Project CLI

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey)
![Status](https://img.shields.io/badge/Status-Active-success)

A Python command-line tool that scaffolds a new Data project in seconds.

It automatically creates a project structure, virtual environment, installs essential packages, initializes Git, and opens the project in Visual Studio Code.

---

## ✨ Features

- 📁 Creates a clean project structure
- 🐍 Creates a Python virtual environment
- 📦 Installs common data science libraries
- 🌿 Initializes a Git repository
- 📝 Generates starter files
- 💻 Opens the project in VS Code
- ⚡ Runs from anywhere after installation

---

## 📂 Project Structure

Running

```bash
new_data_project marketlink
```

creates:

```text
marketlink/
│
├── .venv/
├── src/
├── tests/
├── data/
├── notebooks/
├── README.md
├── requirements.txt
├── config.py
├── main.py
└── .gitignore
```

---

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/LukmanAbdulkadri1/new_data_project.git
```

Move into the project

```bash
cd new_data_project
```

Install

```bash
pip install -e .
```

---

## 🚀 Usage

Create a new project

```bash
new_data_project "Project_name"
```

Example

```bash
new_data_project GoogleAnalytics
```

The CLI will:

- Create folders
- Create a virtual environment
- Install packages
- Initialize Git
- Open VS Code
